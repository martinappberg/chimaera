# First-party application presentation boundary

The kept pane now loads the finite optional host adapter. Account/Settings presentation extraction remains separate. The trusted build exports either a literal installed-entry facade or null; no runtime URL selector, private public dependency, new account client or authority is introduced. The trusted assembly provides one exact runtime service object per window and an already-selected module; installation/signature/entitlement checks are separate gates.
