faq

Good to know

What kind of tool is Chimaera?
An agent workbench: a folder-centered place to work with agents and their outputs. It combines conversations, file viewing, lightweight editing, terminals, review, and project context. Start with one agent and a local folder; add more agents, remote machines, or extensions when they help.
Which agents can I use?
Chimaera runs Claude Code, Codex, Antigravity, and Grok Build themselves, using your provider accounts and the skills and connections configured on the workspace’s host. Claude Code and Codex also support switching between chat and their real terminal UI. See agent support.
How do accounts and billing work?
Use your own agent-provider accounts on the host where the agents run. Chimaera launches the agent CLIs using those accounts. Your provider handles authentication, usage limits, and billing for the mode you use.
How does it keep project context together?
Session history and Timeline connect the work to the agents and files involved. With a knowledge plugin enabled, you can browse recorded findings, decisions, and handoffs beside the project. Your files remain on the workspace’s host, with uploads and downloads for moving them where you need them.
What can I work on?
You can use a local folder for writing, working with data, building software, or mixed projects. Remote hosts and Slurm jobs extend where that workspace can run. They are optional.
What platforms are supported?
macOS on Apple Silicon, Linux (AppImage, .deb, and .rpm), and Windows in beta with a WSL2 daemon. See platform setup. Chimaera is pre-release and moving quickly.
