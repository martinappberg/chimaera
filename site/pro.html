Chimaera Pro.

An optional service for your agent workbench: keep remote hosts connected, add a personal cloud machine, and continue local work when your laptop sleeps.

The free app remains complete: local workspaces, SSH remotes, agents, terminals and previews work without a Pro account.

Read the beta statusFree app documentation

Three parts, one service.

These capabilities are being tested together before paid launch.

Kept connections

A dedicated service holds your SSH connections. Signed-in devices reach the same remote workspaces, with interactive login and two-factor prompts when a host needs them.

A personal cloud machine

Run the same workbench on Linux, sign in to your own agent subscriptions, and open projects from a Git URL. The machine sleeps when idle; cloud hours count while it is awake.

Laptop and cloud handoff

Open local projects are mirrored with uncommitted work and agent history. Sleep handoff and offline takeover are being verified. A project can be excluded with “Never mirror this project.”

Private beta, before paid launch.

Access is by invitation. Public signup and paid subscriptions are not open.

Use the phone browser

The browser uses the same workbench. Terminals open in viewing mode, so checking progress does not resize a running terminal. Take control when you want to type.

Know the limits

Cloud work runs on Linux. Mac-only steps wait for the laptop. Plain terminals do not become the same running process on another machine. Offline takeover can create a separate agent fork.

Keep control of access

Account sign-in requires two-factor authentication. Device controls include sign out everywhere. Agent credentials stay on the machine where you sign in; they are excluded from project mirroring.

Planned subscriptions.
